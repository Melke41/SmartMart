Project name: SmartMart — Retail Store Management System
Description: A Java Swing desktop application for managing retail store operations including inventory, sales, employees, suppliers, and reporting. Built with Java OOP principles and SQLite backend.
Tech stack: Java, Java Swing, SQLite, JDBC
Roles: Admin, Manager, Cashier
Modules: Inventory, POS/Sales, Employee Management, Supplier Management, Reporting, Role-based Authentication
Course: Object Oriented Programming — CoSc2051, Addis Ababa University, 2025
